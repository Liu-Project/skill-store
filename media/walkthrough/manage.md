## Keep skills up to date

The **Installed** view shows every managed skill, its version, and whether an update is available.

- Check the box to opt a skill into automatic updates.
- Use **Check for Skill Updates** to scan all installed skills at once.
- Uninstall removes only directories created by SkillStore, never arbitrary folders.

Auto-update checks run on startup and then at the interval configured by `skillstore.autoUpdateIntervalMinutes`.
